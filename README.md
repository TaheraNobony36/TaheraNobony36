## 🌊 Flood Prohori AI

### Four-Zone IoT & AI-Based Flood Early Detection and Emergency Warning System

A modular flood-monitoring prototype combining **distributed IoT sensing, real-time analytics, computer vision, weather context, and emergency warning mechanisms**.

**✨ Key Features**

* 🌊 Four independent flood-monitoring zones
* 📏 Non-contact water-level measurement using HC-SR04
* 📈 Water-level rate-of-rise analysis
* 📡 433 MHz wireless telemetry
* 🧠 Multi-sensor risk assessment
* 👁️ OpenCV-based visual/flow analysis
* 🌦️ Location-based weather context
* 📊 Real-time Streamlit dashboard
* 🔔 Local LCD & buzzer warnings
* 📱 Mobile/cloud monitoring & alerts
* 🗃️ Historical data storage and analysis
* ⚠️ Risk classification: Low / Moderate / High / Critical

**Tech:** `Arduino` `Python` `OpenCV` `NumPy` `Pandas` `SQLite` `Streamlit` `Plotly` `Firebase/MQTT` `Weather API`

**Focus:** `IoT` `Computer Vision` `Real-Time Monitoring` `Data Analytics` `Early Warning Systems`
